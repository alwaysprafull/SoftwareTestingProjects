# 🧪 SoftwareTestingProjects

Manual QA Testing Porject - A comprehensive and practical resource for Manual QA Testing — featuring test case templates, detailed bug report samples, structured test plans, and real-world testing scenarios. This repository packed with real-world examples, reusable templates, and step-by-step documentation to help QA professionals and beginners ensure software quality with confidence.

---
## 📘 Overview

This repository is your complete starter and reference kit for Manual Software Testing. Whether you're preparing for a QA job, documenting a new feature, or improving a product's quality, this resource covers all the essentials:

- 📄 Test Case Templates (Excel + Markdown)
- 🐞 Bug Report Samples with clear severity and priority
- 📋 Detailed Test Plans & Test Strategies
- ✅ QA Checklists for Web, Mobile, and API Testing
- 💡 Realistic Test Scenarios based on actual projects

---

## 📋 Test Plans

Test Plans provide a high-level view of the testing strategy, scope, schedule, and resources. This section includes:

- 📌 **Master Test Plan Template**
- 🧩 **Feature-Specific Test Plans** (e.g., Login Module, Checkout Flow)
- 📆 **Test Schedule and Milestones**
- 🔍 **Entry/Exit Criteria**

> 📂 Folder: `/test-plans/`  
> Formats: `.docx`, `.pdf`, `.md`

---

## ✅ Test Cases

Test Cases are the core of manual testing. This section includes:

- 🧪 **Test Case Templates** (Web, Mobile, API)
- 🔁 **Reusable Test Cases** for common modules like Login, Signup, and Search
- 📊 **Test Case Traceability** with requirement mapping
- 🧾 **Test Case Execution Reports**

> 📂 Folder: `/test-cases/`  
> Formats: `.xlsx`, `.csv`, `.md`

Each test case includes:

- Test Case ID  
- Test Scenario  
- Preconditions  
- Test Steps  
- Expected Result  
- Actual Result  
- Status (Pass/Fail)
